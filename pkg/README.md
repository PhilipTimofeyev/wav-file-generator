# WAV File Generator



This project uses Rust to build a basic wave file from scratch, creating an audible sine wave. As well as implementing the generator using WebAssembly. 

It's purpose is to better understand the fundementals of the Wave audio format and how it can be generated efficiently through the language of Rust, as well as becoming more familiar with Wasm and the wasm-bindgen crate.

[Project Link](https://wav-generator-sine.netlify.app/)
